# Security boundaries

Source availability and passing tests are not an independent audit or permission to use customer funds.

- Agents propose; owners approve exact financial actions. Model output is untrusted input.
- Native libraries calculate candidates and have no signing authority.
- Reservations survive ambiguous submissions. Recover the original order before trying another.
- Signing material stays in the owner-controlled signer; provider credentials are environment references.
- Public downloads use an allowlist. Runtime databases and operator configuration are private.
- DataPass entitlement and rights declarations do not establish upstream legal ownership.
- Token issuance is protocol-specific and capped; it is not proof of revenue or miner profitability.

Do not publish keys or customer data in an issue. Use GitHub private vulnerability reporting
when enabled; otherwise contact a maintainer privately before sharing an exploit.
No response-time SLA is claimed.
