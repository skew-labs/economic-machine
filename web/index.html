GETTING STARTED
One workspace. Four steps.
  1. Connect your account
    Sign in with your wallet. In Connections, choose an API and reference the keys stored on your server.
  2. Set a shared budget
    In Agents & limits, choose connected APIs, allowed tasks and spending caps.
  3. Give an agent a job
    Name your agent, assign its policy and choose the tasks it can run. Use its API key from your agent’s environment.
  4. Follow the outcome
    Review agent runs and receipts. Order desk prepares exchange orders; Service payments tracks external purchases.
The hosted runtime does not transmit live exchange orders. Developer lab uses sample inputs and cannot move funds.
