# SKEW Tasks — controlled agentic commerce

SKEW gives a buyer a typed task, price ceiling and exact purchase proposal. Only the buyer approves spending. PayPal sandbox Orders v2 handles USD order approval and capture; the engine independently reads the exact merchant, currency, amount and capture before releasing a result. Unknown responses remain attached to the original order. Verified webhooks trigger reconciliation, cancellation does not erase a paid obligation, and confirmed refunds revoke future delivery access.

The present admitted worker cleans business CSV data. Five categories can be drafted, but unimplemented services are not offered as finished paid work. Native local CSV execution is a free engine path and is not evidence of PayPal payment.

Contribution links: GitHub PR13 for recovery, PR14 for MCP, PR15 for the unified conversation and PR16 for evidence. Existing PR2 checkout adapter remains part of the base.
