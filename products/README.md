# SKEW tools

- [Engine](engine/README.md): programs, budgets, connections and execution records.
- [Atlas](atlas/README.md): public compute-price observations and provenance.
- [DataPass](datapass/README.md): publication, access licenses and delivery checks.
- [Mining](mining/README.md): work verification and token reward contracts.
- [Swap / Fuel](fuel/README.md): gas acquisition and persistent swap recovery.
- [SiteLens](sitelens/README.md): facility capacity scenarios.

One repository keeps shared types, contracts, Python bindings and browser clients compatible.
The guides link to the real implementation; the product folders do not duplicate shared code.
