# Read-only navigation adapter

[navigation.py](../../src/economic_machine/navigation.py) matches a bounded
English/Korean command grammar before model interpretation. Product-owned
catalog identity and route guards remain authoritative. Ambiguous public
addresses require a view or network choice rather than an inferred identity.

The [native selector](native/router.cpp) uses generated phrase tables and a
[hash-checking Python boundary](../../src/economic_machine/native_navigation.py).
[generate_registry.py](generate_registry.py) compiles an explicitly supplied
catalog, chart rules and reviewed alias specification. Generated customer
catalogs, private UI and deployment records are not distributed.

Exact local commands do not require model availability. Only unresolved natural
language may reach a separately authorized model interpreter. This adapter does
not import financial execution workers or grant order authority.
